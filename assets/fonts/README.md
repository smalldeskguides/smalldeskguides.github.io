# Bundled font provenance

The existing Latin normal weight-variable Fraunces and Inter files are unchanged.
They are byte-identical to these Fontsource Variable 5.3.0 distribution members:

| Asset | Matching package | SHA256 |
| --- | --- | --- |
| `fraunces-latin-wght-normal.woff2` | `@fontsource-variable/fraunces@5.3.0` | `7f9d191d999336d3b9790afa72e1358e50a13b06d4f289341e92a311967a80f9` |
| `inter-latin-wght-normal.woff2` | `@fontsource-variable/inter@5.3.0` | `3100e775e8616cd2611beecfa23a4263d7037586789b43f035236a2e6fbd4c62` |

Reproducible sources are the [Fraunces archive](https://registry.npmjs.org/@fontsource-variable/fraunces/-/fraunces-5.3.0.tgz)
and [Inter archive](https://registry.npmjs.org/@fontsource-variable/inter/-/inter-5.3.0.tgz).
Their npm SHA512 integrity values and the selected font bytes were checked.
The original acquisition source/version is unknown; this comparison does not
claim that 5.3.0 was the original download. Package metadata identifies Google
Fonts as its source, with distribution identifiers Fraunces v38 and Inter v20;
these are not independently established upstream binary release versions.

Both matching packages declare `OFL-1.1`. Their complete license and attribution
texts are copied unchanged as [Fraunces package notice](licenses/Fraunces-Fontsource-LICENSE.txt)
and [Inter package notice](licenses/Inter-Fontsource-LICENSE.txt). These include
the SIL Open Font License 1.1 terms. The package headers refer to an italic file
as well as the normal family; that supplied attribution has been retained intact.

Complete supplemental [Fraunces Google Fonts notice](licenses/Fraunces-Google-Fonts-OFL.txt)
and [Inter Google Fonts notice](licenses/Inter-Google-Fonts-OFL.txt) are retained
from pinned primary sources:

- [Fraunces in Google Fonts](https://github.com/google/fonts/blob/581699fcc0df7715a0f944e28b1a18d38e4aad62/ofl/fraunces/OFL.txt).
- [Inter in Google Fonts](https://github.com/google/fonts/blob/b0928647ba26c8d55548aa19feb2f7aeba622d4a/ofl/inter/OFL.txt).
- Project sources: [Fraunces](https://github.com/undercasetype/Fraunces/blob/284bc5ea73b1233a05d6ec644e641b9404cba8a0/OFL.txt)
  and [Inter](https://github.com/rsms/inter/blob/3ac1bd32a473ea60d40d8f444820247e96dd7e70/LICENSE.txt).

The supplied copyright years differ: Fontsource says Fraunces 2020 and Inter
2016; Google Fonts says Fraunces 2018 and Inter 2020. The primary project notices
say Fraunces 2018 and Inter 2016. The notices preserve those exact attributions
rather than inventing a reconciled year. No font has been replaced or relicensed.

[`provenance.json`](provenance.json) records the font, archive and notice hashes
and pinned source references. The offline site check verifies the bundled files
and full notices against that record. A future font update must preserve its
actual applicable notices and update the provenance from verified source bytes.
These font licenses do not grant a license to unrelated guide text, images or
site code; no blanket project license is inferred.
